# La Burgueria

Sitio web estático responsive para La Burgueria, creado a partir de las fotografías y carta proporcionadas.

## Sistema visual

- Base: `#101010` sobre `#f5f4f0`; las imágenes se muestran en monocromo para no romper la identidad.
- Tipografía: Archivo Black para titulares y Barlow Condensed para lectura, navegación y precios.
- Espaciado: una escala de cinco pasos reutilizada en toda la interfaz.
- Forma: radio mínimo, radio pequeño y píldora; bordes de 1–2 px y una única sombra dura.
- Movimiento: transiciones cortas con una curva común, revelados discretos y compatibilidad con `prefers-reduced-motion`.

## Abrir el proyecto

No requiere instalación. Abre `index.html` en un navegador o sírvelo desde cualquier servidor estático.

## Contenido

- Carta filtrable por categorías con precios de la imagen proporcionada.
- Navegación móvil, llamadas directas y enlace a Instagram.
- Fotos originales incorporadas en `assets/`.
- Diseño responsive con soporte para reducir movimiento.
